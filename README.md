# 학교 업무 런처

[Windows 설치 파일 받기](https://github.com/parksd1128/school-work-launcher-releases/releases/latest/download/ParkSD1128.SchoolWorkLauncher-win-Setup.exe)

학교 업무 목록을 바탕화면과 단축키로 빠르게 여는 Windows 10/11 x64 앱입니다.

1. 위 링크에서 설치 파일을 받아 한 번 실행하세요. 관리자 권한이 필요하지 않습니다.
2. 바탕화면의 **학교 업무 런처** 또는 **Ctrl+Alt+Space**로 목록을 여세요.
3. 이후 Windows 로그인 때 자동 시작하고, 새 버전은 자동으로 받아 다음 런처 시작 때 적용합니다. 트레이 메뉴에서 바로 적용할 수도 있습니다.

자동 시작은 런처를 오른쪽 클릭한 뒤 **Windows 로그인 시 자동 실행**에서 끌 수 있습니다. 기존 ZIP 버전의 개인 배치·숨김 설정은 유지됩니다. Windows 설정의 설치된 앱에서 제거할 수 있습니다.

현재 설치 파일은 코드 서명되지 않았으므로 Windows에서 확인되지 않은 게시자 경고가 나올 수 있습니다. 관리되는 학교 PC에서 정책으로 설치가 제한되면 담당자에게 설치를 요청하세요.

[학교 업무 웹 홈](https://school-work-hub.parksd1128.chatgpt.site/)

이 저장소에는 설치 파일·자동 업데이트 파일·사용 안내만 게시합니다. 각 릴리스의 `checksums.sha256`에서 파일의 SHA-256 값을 확인할 수 있습니다.
